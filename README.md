# AFROBELLEZA BARBER SHOP 💈🇲🇽

Application mobile professionnelle et système de gestion complet pour **Afrobelleza Barber Shop** (Mexique).

---

## 🚀 Kòman pou w lanse pwojè a (Kreyòl)

### 1. Enstale depandans yo
Louvri yon tèminal nan dosye pwojè a epi tape:
```bash
npm install
```

### 2. Lanse aplikasyon an pou devlopman
```bash
npm run dev
```
Aplikasyon an ap louvri sou: `http://localhost:3000`

### 3. Bati epi lanse pou pwodiksyon (Deploy sou Web la)
```bash
npm run build
npm start
```

---

## 🌐 Kòman pou w pibliye sou Web la (Vercel, Render, Railway, VPS)

### Opsyon 1: Render / Railway / VPS (Full-Stack ak Backend & Database)
1. Mete dosye yo sou GitHub.
2. Konekte repo GitHub ou sou [Render](https://render.com) oswa [Railway](https://railway.app).
3. Chwazi **Node.js Environment**.
4. Build command: `npm install && npm run build`
5. Start command: `npm start`

### Opsyon 2: Vercel / Netlify (Frontend sèlman)
1. Build command: `npm run build`
2. Output directory: `dist`

- Lè aplikasyon an ouvri pou premye fwa, li mande: « **Quel est votre nom ?** »
- Si ou tape egzakteman: **`AFROBELLEZA ADMIN`**, ou gen aksè dirèk nan tablodbò administrasyon an pou kontwole tout bagay:
  - Chanje pri, sèvis, orè
  - Bouton Louvri / Fèmen
  - Chanje foto, logo, koulè, tèks
  - Gade epi jere randevou ak mesaj kliyan yo
- Tout lòt moun ki tape non yo ap rantre otomatikman kòm **Kliyan** san okenn mesaj erè.
